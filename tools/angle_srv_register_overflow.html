ANGLE / D3D11: shader-resource register overflow

A fragment shader that uses all MAX_TEXTURE_IMAGE_UNITS samplers and reads a std140 uniform block whose single member is a large array crashes the GPU process on ANGLE's D3D11 backend. Affects Chrome and Firefox on Windows.

Note: the crashing case kills the browser's GPU process. Other tabs using WebGL will lose their contexts. Nothing is written to disk.

Expected: both cases draw, or WebGL reports an error.
Actual: the control case draws; the failing case kills the GPU process.

Observed crash signature (Firefox, about:crashes):

libGLESv2.dll gl::LogMessage::~LogMessage()                  common/debug.cpp
libGLESv2.dll rx::StateManager11::setShaderResourceInternal<...>  d3d11/StateManager11.cpp
libGLESv2.dll rx::StateManager11::syncUniformBuffersForShader     d3d11/StateManager11.cpp
libGLESv2.dll rx::StateManager11::syncUniformBuffers              d3d11/StateManager11.cpp
libGLESv2.dll rx::StateManager11::updateState                     d3d11/StateManager11.cpp
libGLESv2.dll rx::Context11::drawElementsInstanced                d3d11/Context11.cpp

Chrome reports the same crash as GpuProcessHost: The GPU process crashed! Exit code: STATUS_ILLEGAL_INSTRUCTION.
